# Git live demo

A one-hour live demo of everything on the Git slides (59 to 76/251), told as one simple story for people who have never used Git

**Start here:** open [STEPS.md](STEPS.md) and follow it top to bottom. You need only VS Code, Git 2.28 or newer and Python. No setup scripts, no accounts, no internet

The demo builds one tiny file in a new folder, `~/git-demo` plus `pretend-github.git` (plays GitHub), `teammate` (a colleague's laptop) and a short-lived `hotfix` folder. Nine parts follow the slide order: get ready, save versions, share work, combine work, conflict, ask the history, undo, urgent fix and hygiene
